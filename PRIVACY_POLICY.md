# Unitify Privacy Policy

**Effective date:** October 26, 2026

Unitify – All-in-One Converter ("Unitify") is an offline utility application.

## Data collection

Unitify does not collect, transmit, sell, rent, or share personal data. The app has no user accounts, advertising, analytics, tracking SDKs, or backend service. Conversion calculations run entirely on the user's device.

## Data stored on the device

Unitify stores the selected theme, decimal precision, default category, favorite conversion pairs, and recent conversion history locally using the platform's application preferences. This data does not leave the device. Users can clear favorites and history from the app's Settings screen. Uninstalling the app also removes its locally stored application data, subject to the device platform's backup settings.

## Permissions and network access

Unitify does not request sensitive Android permissions and does not require an internet connection.

## Children

Because Unitify collects no personal data, it does not knowingly collect personal information from children.

## Changes

If Unitify's data practices change, this policy must be updated before a release containing those changes is published.
